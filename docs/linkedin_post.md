# Post para LinkedIn

Estou desenvolvendo um projeto de analise de dados sobre o Campeonato Brasileiro Serie A na era dos pontos corridos.

A ideia foi sair de uma simples tabela de resultados e construir uma base analitica capaz de responder perguntas esportivas e financeiras sobre o Brasileirao:

- quais clubes mais pontuaram no periodo;
- como evoluem jogos, gols, publico e cartoes;
- quanto cada clube mandante arrecadou em receita bruta e liquida;
- qual o ticket medio por clube;
- como comparar ate tres clubes financeiramente;
- qual o historico de confronto direto entre dois times.

O projeto combina coleta, tratamento e validacao de dados publicos de fontes como CBF, Sr.Goool e RSSSF/RSSSF Brasil. Uma parte importante do trabalho foi lidar com inconsistencias reais de dados historicos: nomes de clubes escritos de formas diferentes, temporadas com ajustes oficiais de pontuacao, partidas com peculiaridades e cobertura financeira parcial.

Depois da consolidacao, criei um dashboard interativo em HTML, CSS e JavaScript, com:

- filtros por ano, clube e dados financeiros;
- ranking de clubes;
- visao financeira por mandante;
- comparativo entre clubes;
- calendario de partidas;
- aba de confrontos diretos;
- escudos dos clubes e identidade visual inspirada no tema.

Esse projeto tem sido uma boa forma de praticar um fluxo completo de analise de dados:

Python + Pandas + coleta web + limpeza de dados + modelagem analitica + validacao + dashboard + storytelling visual.

Ainda esta em evolucao, mas ja esta em um ponto bem interessante para portfolio.
